Now — Almawave Labs, 2025 – present

Designing the AI architecture of an enterprise product

I'm responsible for the AI architecture: how LLM agents, workflows and services work together to process documents at scale. Follow a document through it:

Large-scale document-processing pipelines turn incoming documents into structured content the rest of the module can work on.

  • Python
  • Docling
  • PyMuPDF

The AI components run as microservices that expose APIs, containerized and deployed on Kubernetes.

  • FastAPI
  • Docker
  • Kubernetes (AKS)

Multi-step AI processing is orchestrated as workflows, so every step is tracked, retried and observable.

  • Temporal.io

LLM agents carry out the document analysis, orchestrated with LangChain and LangGraph.

My focus: how the agents are designed and orchestrated.

  • LangChain
  • LangGraph

Results live in a document database, and a cost-tracking system attributes LLM spend to each stage of the pipeline.

I built the stage-level cost tracking, so AI costs stay measurable.

  • MongoDB

An agent that writes the tests

A LangGraph agent that generates tests automatically (pytest, httpx) and is integrated into the team's pre-deployment testing framework.

Owner of the AI architecture
